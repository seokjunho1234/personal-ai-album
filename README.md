# 소담

> 소중한 오늘을 소담히 담아요.

아이폰 홈 화면에 설치해 사용하는 우리만의 개인 앨범 PWA입니다.

## 현재 기능

- 여러 사진 가져오기
- 날짜별 자동 정리
- 전체 화면 사진 보기
- 즐겨찾기와 삭제
- 선택한 사진으로 앨범 만들기
- 앨범 이름 수정과 앨범 삭제
- IndexedDB 기기 저장
- MYBOX 동기화와 백업·복원
- 오프라인 앱 셸
- iPhone 홈 화면 설치 지원

> 현재 사진 원본은 브라우저의 IndexedDB에 저장됩니다. 중요한 사진의 유일한 백업으로 사용하지 마세요.

## 로컬 실행

정적 파일 서버라면 무엇이든 사용할 수 있습니다.

```powershell
npx.cmd serve .
```

서비스 워커와 PWA 설치는 `localhost` 또는 HTTPS 환경에서 동작합니다.
